# EasyBeat Maker

Einfache Musik-App im Browser. Ein Satz, ein Genre, ein Klick.

## Live

Nach dem Aktivieren von GitHub Pages:

**https://pat840.github.io/easybeat-maker/**

## GitHub Pages einschalten (einmalig)

1. Im Repo auf **Settings** gehen.
2. Links **Pages** wählen.
3. Unter *Build and deployment*:
   - Source: **GitHub Actions**
4. Speichern. Der Workflow *Deploy GitHub Pages* startet automatisch.
5. Nach 1–2 Minuten die URL oben öffnen.

Falls GitHub Actions noch nicht freigeschaltet ist: Source **Deploy from a branch**, Branch **main**, Ordner **/ (root)**.

## Nutzung

Song-Wunsch eintippen, Genre wählen, **Song erstellen**. Danach abspielen oder herunterladen (WAV, frei nutzbar).
